# Colorize & Palette Governance Guide

## Brand Color Tokens (GCEE Theme)
- **Primary Brand (Teal/Cyan)**:
  - `brand-50` (`#eaf8fa`) - Subtle tinted backgrounds & active tab pills
  - `brand-100` (`#d0f1f5`) - Card highlight backgrounds
  - `brand-500` (`#01889f`) - Primary brand action color, icons, links
  - `brand-600` (`#017286`) - Hover state for primary buttons & dark accents
  - `brand-700` (`#015b6d`) - Deep text & focused borders
  - `brand-900` (`#063f4c`) - Header ribbons & dark surface containers
- **Warm Accent (Amber/Gold)**:
  - `accent-500` (`#f59e0b`) / `accent-600` (`#d97706`) - Announcements, highlights, badge accents, rank tags
- **Semantic Colors**:
  - Success: `emerald-600` (NIRF Top Rank, NAAC A+ badge, Active admissions)
  - Warning: `amber-600` (Deadlines, Exam fee dates)
  - Critical/Urgent: `rose-600` (Emergency circulars, Anti-ragging helpline)
