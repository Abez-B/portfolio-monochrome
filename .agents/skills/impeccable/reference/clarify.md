# Clarify & UX Copywriting Guide

## Academic UX Copy Guidelines
1. **Direct Action Verbs**:
   - Prefer "Download 2024–2025 Syllabus (PDF)" over "Click here".
   - Prefer "Apply for TNEA Counselling" over "Submit".
   - Prefer "Verify Roll Number & Results" over "Proceed".

2. **Clarity in Disclosures & Notices**:
   - Always state the document date, circular reference number, and target audience (e.g. "Ref: GCEE/EXAM/2025/08 | Dated: 12 Aug 2025 | For: B.E. 3rd & 5th Semester").
   - Indicate file size and format for downloads (e.g. `[PDF, 2.4 MB]`).

3. **Status and Feedback**:
   - Provide reassuring confirmation on contact submissions and grievance ticket generation.
