# Typographic Hierarchy & Font System Guide

## Font Pairings & Roles
- **Display Font (`font-display`)**: `Plus Jakarta Sans` for headers, page titles, statistics, badges, and prominent callouts.
- **Body Font (`font-body`)**: `Inter` for paragraphs, descriptions, tables, and dense data lists.
- **Mono Font (`font-mono`)**: `JetBrains Mono` for course codes, TNEA codes, roll numbers, and technical metadata.

## Rules of Typographic Scale
- **Hero Title**: `text-4xl md:text-5xl lg:text-6xl font-extrabold tracking-tight`
- **Section Heading**: `text-2xl md:text-3xl font-bold tracking-tight text-slate-900`
- **Subheading**: `text-lg md:text-xl font-medium text-slate-600`
- **Body Text**: `text-base text-slate-700 leading-relaxed`
- **Caption / Meta**: `text-xs md:text-sm text-slate-500`
- **Numbers / Metrics**: `text-3xl md:text-4xl font-bold text-brand-600 font-display`
