# Layout, Grid & Spatial Harmony Guide

## Page Container Architecture
- **Max Width**: `max-w-7xl mx-auto px-4 sm:px-6 lg:px-8`
- **Section Spacing**: `py-12 md:py-16 lg:py-20`
- **Component Gap**: `gap-6 lg:gap-8`

## Grid Standards
- **Feature Cards**: `grid grid-cols-1 sm:grid-cols-2 lg:grid-cols-3 gap-6`
- **Sidebar + Main Content Layout**: `grid grid-cols-1 lg:grid-cols-4 gap-8` (Sidebar `lg:col-span-1`, Main `lg:col-span-3`)
- **Key Statistics Strip**: `grid grid-cols-2 sm:grid-cols-4 gap-4 md:gap-6`

## Whitespace & Visual Breathing Room
- Avoid cramped borders and dense text clumps.
- Use distinct background alternations (`bg-white` vs `bg-slate-50` / `bg-brand-50/30`) to visually segment complex pages.
